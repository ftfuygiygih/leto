# Пульт — менеджер Telegram-ботов

Веб-панель: вставляешь токен бота (от @BotFather), он появляется в списке.
Переключателем включаешь/выключаешь приём сообщений (long polling), в
развёрнутой карточке можно отправить сообщение от имени бота в конкретный
chat ID, посмотреть последние входящие сообщения — и разослать одно
сообщение всем, кто когда-либо писал боту (режим рассылки).

**Важно про рассылку:** Telegram не разрешает слать сообщения тем, кто не
писал боту первым — рассылать можно только по чатам, которые уже есть в
списке "известных" (появляются там автоматически, пока бот включён и
кто-то ему пишет). Это не инструмент для спама незнакомым людям, а способ
написать всем своим подписчикам разом, как рассылка в Telegram-каналах.

### Режим рекламы

В карточке бота есть блок «Режим рекламы»:

- **Рекламный текст** — то, что отправляется автоответом и/или по расписанию.
- **Команды-триггеры** — например `/start, /help`: на любую из этих команд
  бот автоматически отвечает рекламным текстом (бот должен быть включён —
  тумблер приёма сообщений).
- **Автоответ** — тумблер включает/выключает автоответ на триггеры.
- **Расписание** — тумблер + время: раз в сутки, в указанное время (по
  времени сервера), рекламный текст автоматически уходит всем известным
  чатам, как обычная рассылка. Расписание работает независимо от тумблера
  приёма сообщений — сервер должен быть просто запущен (см. предупреждение
  про "засыпание" на бесплатном плане Render ниже).

Не забудь нажать «Сохранить» после изменения этих настроек.

## Как это устроено

- `server.js` — Node.js/Express сервер. Он хранит список ботов и их токены,
  сам ходит в Telegram Bot API (`getMe`, `getUpdates`, `sendMessage`).
  Токены никогда не попадают в браузер.
- `public/index.html` — фронтенд, обращается только к своему же серверу.
- `bots.json` — файл, куда сохраняется список ботов между перезапусками.
- `chats.json` — список чатов, которые писали каждому боту (нужен для рассылки).

## Локальный запуск

```bash
npm install
npm start
```

Открой http://localhost:3000

## Деплой на Render

1. Залей эту папку в репозиторий на GitHub (или GitLab/Bitbucket).
2. На render.com → **New** → **Web Service** → подключи репозиторий.
3. Настройки:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Environment**: Node
   - План можно брать Free.
4. Нажми Deploy — через пару минут Render даст ссылку вида
   `https://твой-сервис.onrender.com`.

### Важно про Free-план Render

- Бесплатный инстанс "засыпает" после ~15 минут без запросов и просыпается
  по первому заходу (с задержкой в несколько секунд) — пока бот "включён",
  но сервис спит, он не опрашивает Telegram. Для реально активного бота
  нужен платный план или внешний пинг, чтобы сервис не засыпал.
- Файловая система на Free-плане не постоянна: при каждом новом деплое
  `bots.json` обнуляется, и список ботов придётся вставлять заново. Если
  нужно сохранять список надолго — можно подключить Render Disk (платно)
  или внешнюю БД.

## Безопасность

Токен бота даёт полный доступ к нему. Сервис никак не ограничивает, кто
может зайти на сайт и добавить/удалить бота — при желании стоит добавить
простую защиту паролем (Basic Auth) перед тем, как давать ссылку кому-то ещё.
